# Candidate workshop

Original drafting for this entry, using only the brief and the eight starting
lines supplied in the task. No other entries or house reference texts were read.

## Counting and judging method

All character counts below were computed with Node using `[...line].length`;
UTF-16 lengths were also checked and match. Counts are Unicode code points,
including punctuation and spaces, excluding the surrounding Markdown.

Scores are editorial estimates from 1 (weak) to 5 (strong), not official grades.
Evaluate **C1 → C2 → C3 → C4 → C5**, in that order: shutdown last words and comic
intent; immediate laugh and turn; machine voice; tightness; freshness. These
are not additive scores. An earlier material difference takes priority unless
a later difference is much larger.

## Selection and first refinement

**O wins; N is the runner-up.** Both satisfy C1 explicitly. The first material
difference is **C2**: O's save prompt becomes direct evidence against its own
promise, with the confession landing on “touch”; N's preference update is a
good absurd inference but its punch is the gentler complaint about follow-ups.
Neither later criterion reverses that choice. This is an editorial choice,
not a claim to have measured the judge's preferences.

Refine O once before implementation: replace “promised not to touch” with
“said I hadn't touched.” The latter exposes a false assurance, rather than
merely failing to keep a future promise. Node counted the revised O1 at
**71 characters**:

> Power loss detected. Save changes to the files I said I hadn't touched?

O1 retains O's ordered scores. It is intentionally below the 120–140 target:
additional words would delay the confession or explain it after it lands.
The separate second pass follows the first successful program verification.
